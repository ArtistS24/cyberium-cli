# Security Policy

## Supported Versions

| Version | Supported |
| :--- | :--- |
| `main` (Latest) | :white_check_mark: |

## Reporting a Vulnerability

As a cybersecurity practitioner, **Denis Albin** treats the security and privacy of this educational client suite with paramount priority. If you identify a session handling flaw, credential leakage risk, or local privilege vulnerability:

1. **Do not file a public issue** disclosing unpatched security vulnerabilities.
2. **Email the report directly** to:
   **albindeniswork@gmail.com**
3. **Please provide**:
   - Affected CLI subcommand, API endpoint, or TUI module
   - Step-by-step reproduction steps or Proof of Concept
   - Impact assessment (e.g. token extraction, unverified API execution)
   - Recommended remediation or patch (if identified)

### Response SLA & Incident Timeline

- **Initial Acknowledgment**: Within 48 hours of receipt.
- **Triage & Reproduction**: Within 5 business days.
- **Remediation & Patch**: Pushed directly to `main` with public attribution upon release.

### Safe Harbor Commitment

Good-faith security research and vulnerability discovery conducted within authorized environments and reported via responsible disclosure will receive full safe harbor protection.
